طريقة استخراج ملف التثبيت Setup.exe بدون تثبيت Python على اللابتوب
===============================================================

المشروع مجهّز لبناء نسخة Windows على GitHub Actions. لن تحتاج تثبيت Python أو أدوات بناء على اللابتوب، لكن تحتاج حساب GitHub واتصال إنترنت لرفع المشروع وتنزيل الناتج.

1) افتح https://github.com وسجّل الدخول أو أنشئ حسابًا.
2) اضغط + ثم New repository.
3) اكتب الاسم WarehouseDesktop واجعله Public مؤقتًا، ثم Create repository.
4) في صفحة المستودع اضغط "uploading an existing file".
5) فك ضغط WarehouseDesktop_Build_Package.zip على اللابتوب.
6) ارفع كل محتويات المجلد، بما فيها المجلد المخفي .github (يحتوي workflow)، ثم اضغط Commit changes.
   مهم: تأكد أن ملف .github/workflows/build.yml موجود في المستودع بعد الرفع.
7) افتح تبويب Actions. إذا ظهر تنبيه لتفعيل Actions فعّله.
8) افتح workflow باسم Build Windows installer، واضغط Run workflow ثم Run workflow.
9) انتظر حتى ينتهي التشغيل بعلامة خضراء. افتح نتيجة التشغيل وانزل إلى Artifacts.
10) نزّل Warehouse-Setup، وفك ضغطه. ستجد Warehouse-Setup.exe. شغّله للتثبيت.

البيانات:
- قاعدة البيانات تُحفظ محليًا في:
  %LOCALAPPDATA%\WarehouseDesktop\warehouse.db
- البرنامج لا يحتاج إنترنت بعد التثبيت، لكن الإنترنت مطلوب لبناء النسخة بهذه الطريقة.
- احتفظ بنسخة احتياطية من قاعدة البيانات بانتظام.

ملاحظات مهمة:
- هذه نسخة أولية، لم تُختبر بعد على طابعتك أو في بيئة ويندوز فعلية.
- قبل إدخال بيانات حقيقية، جرّب فاتورة شراء ومبيعات وطباعة وتأكد من الرصيد.
- عند رفع المشروع إلى GitHub Public، يصبح الكود متاحًا للآخرين. لا ترفع بيانات مخازن أو معلومات سرية. هذا المشروع حاليًا لا يحتوي قاعدة بيانات فعلية.
- إذا أردت خصوصية أكثر، اجعل المستودع Private إذا كان حسابك يسمح بذلك.
